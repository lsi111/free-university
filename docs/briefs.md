# 학과별 교시 구성안

각 항목은 **제안**이다. 사실과 교육 효과를 위해 필요하면 교시 순서와 내용을 조정해도 된다. 공통 줄기는 6교시이고, 교시 id는 `<접두어>-01`~`<접두어>-06`이다. `formula`는 수식 기능을 쓸 수 있다는 뜻이다. 표시가 없으면 `features`는 `[]`이다. 모든 사례는 가상으로 쓰고, 실제 기관·인물·통계를 사실 주장으로 쓰지 않는다.
